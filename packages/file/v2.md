1. createFile changes

no more createFile(),

fs = $inject(FileSystem);
but fs.createFile()

Implementation of FileSystem is provided by the environment.
- browser -> InMemoryFileSystem | IndexedDBFileSystem
- node -> NodeFileSystem
- react-native -> InMemoryFileSystem

FileLike is still the common interface for files inside Alepha.

2. FileSystem interface

export abstract class FileSystem {
  file(
    source:
      string |
      Buffer |
      ArrayBuffer |
      StreamLike |
      File |
      { path: string } | // new
      { url: string } // new
  ,
  options: {
    type?: string;
    name?: string;
    size?: number;
  }): FileLike;

  save(
    file: FileLike,
    filepath: string | {
      filepath: string;
      encoding: string;
    }
  )

  readFile(path): Promise<FileLike>; // iso node fs.readFile
  writeFile() // iso node fs.writeFile

  mkdir(): Promise<void>; // recursive by default
  readdir(): Promise<(FileLike | string)[]>; // file or directory names
  exists(): Promise<boolean>;
  rm(path, { recursive?: boolean } = {}): Promise<void>;
  rename()
  copyFile()
  // more soon ...


  tmpdir(): string; // generate a temp directory path (does not create the directory)
  join(...paths: string[]): string;
}

3. Global helpers

Move all helper function of helpers/createFile() to a single class FileUtils with normal methods.

---- Playground ----

const alepha = Alepha.create();
const fs = alepha.inject(FileSystem);

const favicon = fs.file({ url: 'https://alepha.dev/favicon.png' });
await fs.save(favicon); // save to current directory as 'favicon.png'
