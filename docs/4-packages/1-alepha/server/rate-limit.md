# Alepha - Server Rate Limit

## Installation

Part of the `alepha` package. Import from `alepha/server/rate-limit`.

```bash
npm install alepha
```

## Overview

Request rate limiting on actions.

**Features:**
- Rate limit configuration per action

## API Reference

### Primitives

- [`$rateLimit`](/docs/reference-primitives-$ratelimit) — Middleware that enforces rate limiting.
