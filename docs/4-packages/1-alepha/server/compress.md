# Alepha - Server Compress

## Installation

Part of the `alepha` package. Import from `alepha/server/compress`.

```bash
npm install alepha
```

## Overview

| Stability | Since | Runtime |
|-----------|-------|---------|
| 3 - stable | 0.13.0 | node, bun|

Response compression.

**Features:**
- Gzip compression
- Brotli compression

## API Reference

### Primitives

- [`$compress`](/docs/reference-primitives-$compress) — * Disable compression for this route.
