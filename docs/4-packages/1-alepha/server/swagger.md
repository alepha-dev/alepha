# Alepha - Server Swagger

## Installation

Part of the `alepha` package. Import from `alepha/server/swagger`.

```bash
npm install alepha
```

## Overview

| Stability | Since | Runtime |
|-----------|-------|---------|
| 3 - stable | 0.9.0 | node, bun|

Automatic API documentation generation.

**Features:**
- Swagger/OpenAPI configuration
- Routes: `GET /swagger/ui`, `GET /swagger.json`

## API Reference

### Primitives

- [`$swagger`](/docs/primitives-$swagger) — Creates an OpenAPI/Swagger documentation primitive with interactive UI.
