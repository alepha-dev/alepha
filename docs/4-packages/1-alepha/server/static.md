# Alepha - Server Static

## Installation

Part of the `alepha` package. Import from `alepha/server/static`.

```bash
npm install alepha
```

## Overview

| Stability | Since | Runtime |
|-----------|-------|---------|
| 3 - stable | 0.3.0 | node, bun|

Static file serving.

**Features:**
- Serve static files from directory
