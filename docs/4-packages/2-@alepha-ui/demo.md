# @alepha/ui - Demo

## Installation

```bash
npm install @alepha/ui
```

## Overview

Component showcase and documentation.

**Features:**
- DemoLayout for demo pages
- DemoHome landing page
- MacWindow component for showcases
- Showcase component for component demos

## API Reference

### Primitives

- [`$uiDemo`](/docs/reference-primitives-$uidemo) — Register Demo UI components and get the DemoRouter instance.
