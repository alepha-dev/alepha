# Alepha - Api Users

## Installation

Part of the `alepha` package. Import from `alepha/api/users`.

```bash
npm install alepha
```

## Overview

Complete user management with support for separate user realms.

**Features:**

- User registration, login, and profile management
- Password reset workflows
- Email verification
- Session management with multiple devices
- Identity management (social logins, SSO)
- Multi-realm user separation
- Credential management
- Entities: `users`, `identities`, `sessions`

## API Reference

### Primitives

- [`$realm`](/docs/reference-primitives-$realm) - Already configured realm for user management.
