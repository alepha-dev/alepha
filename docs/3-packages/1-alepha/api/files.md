# Alepha - Api Files

## Installation

Part of the `alepha` package. Import from `alepha/api/files`.

```bash
npm install alepha
```

## Overview

| type | quality | stability |
|------|---------|-----------|
| backend | standard | stable |

File management endpoints.

**Features:**
- Upload/download endpoints
- File metadata storage
- TTL-based expiration
- Storage statistics
