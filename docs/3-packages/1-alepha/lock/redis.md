# Alepha - Lock Redis

## Installation

Part of the `alepha` package. Import from `alepha/lock/redis`.

```bash
npm install alepha
```

## Overview

Plugin for Alepha that provides a locking mechanism.

## API Reference

### Providers

- [`RedisLockProvider`](/docs/reference-providers-redislockprovider) - Locks over Redis `SET NX PX`.
