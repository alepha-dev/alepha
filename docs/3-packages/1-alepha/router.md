# Alepha - Router

## Installation

Part of the `alepha` package. Import from `alepha/router`.

```bash
npm install alepha
```

## Overview

| Stability | Since | Runtime |
|-----------|-------|---------|
| 3 - stable | 0.2.0 | node, bun, workerd, browser, expo|

Frontend routing infrastructure.

**Features:**
- Route state management
- Navigation methods
- Route matching
