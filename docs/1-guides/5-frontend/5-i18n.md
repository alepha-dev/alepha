# Internationalization (i18n)

So you want to conquer the world market. First step: stop assuming everyone speaks English.

The `@alepha/react/i18n` module gives you SSR-friendly internationalization without the bloat. Lazy-loaded translations, type-safe keys, and automatic language detection.

## Setup

### Define Dictionaries

Create translation files and register them with `$dictionary`:

```typescript
// AppRouter.ts
import { $dictionary } from "@alepha/react/i18n";

class AppRouter {
  en = $dictionary({
    lazy: () => import("./translations/en.ts"),
  });

  fr = $dictionary({
    lazy: () => import("./translations/fr.ts"),
  });

  de = $dictionary({
    lazy: () => import("./translations/de.ts"),
  });
}
```

### Translation Files

Each translation file exports a default object:

```typescript
// translations/en.ts
export default {
  // Simple strings
  welcome: "Welcome",
  goodbye: "Goodbye",

  // With placeholders
  greeting: "Hello, {name}!",
  items: "{count} items",

  // Nested keys
  nav: {
    home: "Home",
    about: "About Us",
    contact: "Contact",
  },

  // Pluralization
  messages: {
    one: "You have 1 message",
    other: "You have {count} messages",
  },
};
```

```typescript
// translations/fr.ts
export default {
  welcome: "Bienvenue",
  goodbye: "Au revoir",
  greeting: "Bonjour, {name}!",
  items: "{count} articles",

  nav: {
    home: "Accueil",
    about: "À propos",
    contact: "Contact",
  },

  messages: {
    one: "Vous avez 1 message",
    other: "Vous avez {count} messages",
  },
};
```

## Using Translations

### The `useI18n` Hook

```tsx
import { useI18n } from "@alepha/react/i18n";

const Greeting = ({ user }) => {
  const { tr, lang, setLang } = useI18n<AppRouter, "en">();

  return (
    <div>
      <p>{tr("welcome")}</p>
      <p>{tr("greeting", { name: user.name })}</p>
      <p>{tr("nav.home")}</p>

      {/* Language switcher */}
      <select value={lang} onChange={(e) => setLang(e.target.value)}>
        <option value="en">English</option>
        <option value="fr">Français</option>
        <option value="de">Deutsch</option>
      </select>
    </div>
  );
};
```

The type parameters are important:
- `AppRouter` - Your router class with dictionaries
- `"en"` - The default/fallback language for type inference

### What `useI18n` Returns

```typescript
const {
  tr,          // Translation function
  lang,        // Current language code ("en", "fr", etc.)
  setLang,     // Change language
  l,           // Localization helper (dates, numbers)
  dictionary,  // Raw dictionary object
} = useI18n<AppRouter, "en">();
```

## Translation Function (`tr`)

### Simple Translations

```tsx
tr("welcome")           // "Welcome"
tr("nav.home")          // "Home"
```

### With Placeholders

```tsx
tr("greeting", { name: "Alice" })  // "Hello, Alice!"
tr("items", { count: 5 })          // "5 items"
```

### Pluralization

Define pluralized translations:

```typescript
// en.ts
messages: {
  zero: "No messages",
  one: "You have 1 message",
  other: "You have {count} messages",
}
```

Use with count:

```tsx
tr("messages", { count: 0 })  // "No messages"
tr("messages", { count: 1 })  // "You have 1 message"
tr("messages", { count: 5 })  // "You have 5 messages"
```

### Fallbacks

If a key is missing, it falls back:
1. Try the requested key in current language
2. Try the same key in default language
3. Return the key itself (useful for debugging)

## Localization Helper (`l`)

Format dates, numbers, and currencies:

```tsx
const { l } = useI18n<AppRouter, "en">();

// Dates
l(new Date(), { date: "short" })     // "1/15/24"
l(new Date(), { date: "long" })      // "January 15, 2024"
l(new Date(), { date: "fromNow" })   // "2 hours ago"

// Numbers
l(1234567.89, { number: "decimal" }) // "1,234,567.89"
l(0.75, { number: "percent" })       // "75%"

// Currency
l(99.99, { currency: "USD" })        // "$99.99"
l(99.99, { currency: "EUR" })        // "€99.99"
```

Formatting respects the current locale:

```tsx
// In French
l(1234567.89, { number: "decimal" }) // "1 234 567,89"
l(99.99, { currency: "EUR" })        // "99,99 €"
```

## Language Detection

### Server-Side

The server detects language from:
1. URL parameter (`?lang=fr`)
2. Cookie (`alepha.lang`)
3. `Accept-Language` header
4. Default language

### Client-Side

Language persists in a cookie. When `setLang` is called:

```tsx
setLang("fr")  // Updates cookie, triggers re-render
```

### URL-Based Language

For `/en/about`, `/fr/about` patterns:

```tsx
home = $page({
  path: "/:lang/",
  loader: async ({ params }) => {
    // params.lang available for language selection
  },
});
```

## Lazy Loading

Translations load on demand. Only the current language bundle is fetched.

```typescript
en = $dictionary({
  lazy: () => import("./translations/en.ts"),
});
```

When switching languages:
1. Request new translation bundle
2. Wait for load
3. Re-render with new strings

No flash of untranslated content.

## Type Safety

The `tr` function is fully typed. Invalid keys are compile-time errors:

```tsx
// Given dictionary with "welcome", "greeting"
tr("welcome")    // ✓ Valid
tr("welcom")     // ✗ Type error: typo
tr("missing")    // ✗ Type error: key doesn't exist
```

Placeholder types are inferred too:

```tsx
// greeting: "Hello, {name}!"
tr("greeting", { name: "Bob" })  // ✓ Valid
tr("greeting", { user: "Bob" })  // ✗ Type error: wrong placeholder
tr("greeting")                   // ✗ Type error: missing placeholder
```

## Common Patterns

### Global Language Context

Wrap your app to provide language context:

```tsx
// AppLayout.tsx
const AppLayout = ({ children }) => {
  const { lang } = useI18n<AppRouter, "en">();

  // Set HTML lang attribute
  useEffect(() => {
    document.documentElement.lang = lang;
  }, [lang]);

  return <div>{children}</div>;
};
```

### Language Switcher Component

```tsx
const LanguageSwitcher = () => {
  const { lang, setLang } = useI18n<AppRouter, "en">();

  const languages = [
    { code: "en", label: "English", flag: "🇺🇸" },
    { code: "fr", label: "Français", flag: "🇫🇷" },
    { code: "de", label: "Deutsch", flag: "🇩🇪" },
  ];

  return (
    <div className="lang-switcher">
      {languages.map((l) => (
        <button
          key={l.code}
          onClick={() => setLang(l.code)}
          className={lang === l.code ? "active" : ""}
        >
          {l.flag} {l.label}
        </button>
      ))}
    </div>
  );
};
```

### Translating Outside Components

For utility functions or services:

```typescript
import { Alepha, $inject } from "alepha";

class NotificationService {
  alepha = $inject(Alepha);

  notify(key: string, params?: object) {
    const tr = this.alepha.i18n.tr;
    const message = tr(key, params);
    // Send notification with translated message
  }
}
```

### RTL Support

Detect right-to-left languages:

```tsx
const { lang } = useI18n<AppRouter, "en">();
const isRTL = ["ar", "he", "fa"].includes(lang);

return <div dir={isRTL ? "rtl" : "ltr"}>{children}</div>;
```

## Project Structure

Organize translations by feature or flat:

```
src/
├── translations/
│   ├── en.ts        # Flat structure
│   ├── fr.ts
│   └── de.ts
```

Or by feature:

```
src/
├── translations/
│   ├── en/
│   │   ├── common.ts
│   │   ├── auth.ts
│   │   └── dashboard.ts
│   ├── fr/
│   │   ├── common.ts
│   │   ├── auth.ts
│   │   └── dashboard.ts
```

Then merge in your main translation file:

```typescript
// translations/en.ts
import common from "./en/common";
import auth from "./en/auth";
import dashboard from "./en/dashboard";

export default {
  ...common,
  auth,
  dashboard,
};
```

## Quick Reference

```typescript
// Define dictionaries
en = $dictionary({ lazy: () => import("./translations/en.ts") });
fr = $dictionary({ lazy: () => import("./translations/fr.ts") });

// Use in components
const { tr, lang, setLang, l } = useI18n<AppRouter, "en">();

// Translate
tr("key")
tr("key", { placeholder: value })
tr("nested.key")

// Localize
l(date, { date: "short" })
l(number, { number: "decimal" })
l(amount, { currency: "USD" })

// Switch language
setLang("fr")
```
