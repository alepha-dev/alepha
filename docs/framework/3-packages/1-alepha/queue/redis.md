# Alepha - Queue Redis

## Installation

Part of the `alepha` package. Import from `alepha/queue/redis`.

```bash
npm install alepha
```

## Overview

Plugin for Alepha Queue that provides Redis queue capabilities.

## API Reference

### Providers

- [`RedisQueueProvider`](/docs/reference-providers-redisqueueprovider) - Redis-backed queue: a LIST for what is deliverable now, and a **sorted set
