# Alepha - React I18n

## Installation

Part of the `alepha` package. Import from `alepha/react/i18n`.

```bash
npm install alepha
```

## Overview

Multi-language support.

**Features:**

- Translation loading
- Locale detection, and the writing direction (`<html dir>`) of the language
- Interpolation, positional (`$1`, `$2`) or named (`{name}`), and localized dates/numbers
- Plurals and select: a variant entry chosen by `count` through `Intl.PluralRules`, or by `select`

## API Reference

### Primitives

- [`$dictionary`](/docs/reference-primitives-$dictionary) - Register a dictionary entry for translations.

### React Hooks

- [`useI18n`](/docs/reference-react-hooks-usei18n) - Hook to access the i18n service.
