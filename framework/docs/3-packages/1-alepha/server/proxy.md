# Alepha - Server Proxy

## Installation

Part of the `alepha` package. Import from `alepha/server/proxy`.

```bash
npm install alepha
```

## Overview

Reverse proxy routing.

**Features:**

- Proxy configuration and routing

## API Reference

### Primitives

- [`$proxy`](/docs/reference-primitives-$proxy) - Creates a proxy primitive to forward requests to another server.
